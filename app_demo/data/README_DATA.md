# Data Files

This folder includes:

```text
Ready_data.csv
```

The app also needs:

```text
Ready_images.pkl
```

`Ready_images.pkl` is not copied here by default because it is approximately 2.48 GB. The Streamlit app defaults to the existing parent project copy:

```text
../Ready_images.pkl
```

For a fully self-contained deployment, copy the file manually into:

```text
Final/data/Ready_images.pkl
```
